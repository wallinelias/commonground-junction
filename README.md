# Common Ground

**Start with the work.**

Common Ground helps people and employers meet through a real work question before a CV shapes the first conversation.

## How it works

1. An employer shares a practical work question and meeting times.
2. A person chooses a question and shares a short story or what they would try.
3. The person asks for a ten-minute conversation.
4. The employer confirms or passes.

Common Ground does not automatically score or rank people, or make hiring decisions.

## About this demo

This is a small, fictional example. It does not create real bookings. It is built with HTML, CSS, and JavaScript and does not use an AI model.

To try it, open `index.html` in a browser.

## Publish with GitHub Pages

Keep `index.html`, `styles.css`, and `app.js` at the top level of the repository. In **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)** and save. GitHub Pages will publish the demo as a website.
